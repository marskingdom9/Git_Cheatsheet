PR: collaboration area where work in a branch is reviewed before merging into another branch 
  Conversation - general PR activity log and open space for community to provide ideas, suggestions, and feedback
  Commits - list of only commits unique to proposed branch
  Checks - results of any automations applied to PR using Actions 
  Files Changed - Diff view showing proposed changes (Before/After) with options to add comments/reviews

Assignee: person(s) most familiar with proposed changes to keep track of who to contact for questions

Review: feedback from collaborators on proposed changes
  Comment - general feedback (no approval or rejection)
  Approve - allow merging if rulesets, code owners, or othe policies enforced
  Request Changes - proposed changes require additional work (Files Changed tab)

Add a Suggestion: button in comment text editor ... inserts specially formatted code block 
Commit Suggestion: author can accept suggestion and commit with button press

Click on modified line number -> Plus icon -> Add Suggestion -> Comment -> Apply Commit Suggestion (Conversation) -> Merge PR -> Delete branch
