Secure Repo Supply Chain

Advanced Security Tab -> Insights (Dependencies)

Dependency Graph: summary of manifest and lock files stored in repo ... Insights -> Dependencies
  
Dependabot Alerts: reference to [GitHub Advisory Database](https://github.com/advisories) to check for known security vulnerabilities and malware 
(reviewed and unreviewed advisories) ... Enable Dependabot -> Security (Vulnerability Alerts) -> Create/Merge/Review PR 

Dependabot Security Updates: Dependabot detects and fixes vulnerable dependencies by opening PRs automatically ... Enable Dependabot Security Updates
Dependabot Version Updates: Dependabot ensures that repo automatically keeps up with latest releases of packages and applications it depends on ... Edit dependabot.yml
